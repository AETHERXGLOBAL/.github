# AETHER X GLOBAL — GitHub Publishing Identity

**Corporate identity:** AETHER X GLOBAL (short form: AETHER X).  
**Scope:** Public-facing repositories, technical correspondence, issue/PR/release descriptions, changelogs and open-source contributions published under the organization's authority.

## Editorial standard

- Present company work under **AETHER X GLOBAL**, with precise technical statements, checked evidence and professional, restrained wording.
- Avoid optional tool-generated signatures, artificial co-author credit, vendor promotion and generator badges in externally published copy.
- Attribute the actual GitHub account, original contributors, third-party projects and their work correctly. Keep source references, valid license notices, mandatory acknowledgments, provenance and audit records intact.
- Never impersonate a human, change author identities, forge signing records, delete historical evidence or assert human-only authorship without support. Be truthful when asked about provenance and comply with applicable platform, upstream and legal disclosure obligations.
- Respect existing branch protection, review, security reporting, external-publication approvals and each project's contribution rules.
- A PR, document or template alone does not update agent/plugin configurations in other repositories.

## Before publication

1. Verify the exact source, status, test results and factual claims.
2. Check public copy for unnecessary vendor/tool credits and for mandatory attribution/disclosure obligations.
3. Confirm actual GitHub actor identity, upstream policy and appropriate approval.
4. Publish through authorized accounts only; retain authentic Git commit/PR/review history.
5. Report the exact published URL and status, distinguishing a draft from an accepted contribution.

**Rule of priority:** Truthful authorship, law, license and upstream/platform rules override editorial presentation.
